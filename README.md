# FORGE Next
A glass-inspired installable web-app foundation.

## Included now
- Home dashboard, profile, custom repeating routine, live workout sessions and history
- Manual food diary with daily estimated kcal, protein, carbohydrate, fat and fibre totals
- Water log and adjustable goal
- Local journal, AI permission toggles, data export and erase
- Responsive glass UI, dark theme, reduced-motion support, PWA manifest and service worker

## Not connected / not yet implemented
- Secure account login and cloud sync
- OpenAI-powered FORGE AI (the AI screen is a preview; no API key is included)
- Automatic food database lookup, barcode/photo recognition, full micronutrient database
- Notifications, calendar, sleep/recovery analytics, advanced charts and media exercise demos
- Native APK packaging

## Privacy
Prototype records are stored in browser localStorage and are not encrypted or synced. The public source code does not contain secrets. Do not use this prototype for sensitive journal or medical data. Add a secure backend, authentication, consent controls, and security review before production use.

## Deploy
Upload the root files to the repository root and the icon files into `assets/`. Enable GitHub Pages from `main` / root.
